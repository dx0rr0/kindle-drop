Setup and phone access

Complete the prerequisite checks and SSH setup in the repository before sending. This page can prepare readings while setup is pending.

  1. make doctor
  2. make check MOUNT=D:/ — run the diagnostic from KUAL, then reconnect USB.
  3. make verify MOUNT=D:/
  4. make key MOUNT=D:/
  5. make pair HOST=YOUR_KINDLE_IP — verify and repeat with its fingerprint.

Use make open LAN=1 for a phone on the same trusted Wi-Fi. Stop this server before changing setup. Keep the phone and OPDS links private.
